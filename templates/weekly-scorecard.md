# Weekly scorecard (5 minutes)

| Metric | Source | This week | Last week | Status |
|---|---|---|---|---|
| Views per listing or post | Platform statistics | | | |
| Saves and favorites | Platform statistics | | | |
| Inquiries | Messages, email | | | |
| Orders and revenue | Orders | | | |
| New email subscribers | Email tool | | | |
| Owner hours (marketing, production) | Time log | | | |
| Utilization | Order book / planned hours | | | |

Status: green on target, amber behind, red off track. Set thresholds in the plan.

Review cadence: weekly (30 minutes), monthly (1 hour, three adjustments), quarterly (stage gate).

Adjustment rule: change one variable at a time and hold for 2 weeks (4 where traffic is low). Stop any action that moves no metric in 8 weeks.
