# ayayai-casos

Anonymized case studies from **ayayai business sessions**: small-business diagnostics and growth plans built with AI, one case per session.

I (Edgar Boada) run these sessions as free pilots while I build an AI-assisted business advisory practice. Every case here is real, anonymized, and published with the client's permission. No client names, handles, figures or recordings appear in this repository.

## What I do
- Structured discovery of a small business: product, customer, price, channels, goals, time, past attempts.
- Analysis with AI assistants: unit economics, funnel math, capacity and time balance.
- A written plan for the owner (and, if useful, a version for a team or advisors): roadmap, first month, first week, metrics, adjustment rules.
- Scenario comparisons that show which plan is likely to work better, and why.
